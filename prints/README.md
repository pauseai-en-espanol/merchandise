## Font handling

**Every `<text>` element has been replaced by `<path>` outlines** of
the Saira Condensed Bold glyphs from `brand/fonts/files/`. The print
files have **zero font dependency** — the printer does not need Saira
Condensed (or any other font) installed.

Italic style for the attribution lines in `cais-extinction-front.svg`
is synthesized with a `skewX(-10°)` transform on the run group (the
chapter only commits the regular weight to the repo).

## Sending to the printer

The SVGs are valid, standalone, and contain only paths + (in the
backs) embedded raster module rects for the QR. Any modern print
shop accepts SVG directly.

If your printer asks for **PDF** instead, convert with **macOS
Preview**:

1. Open the SVG in Safari or Chrome
2. File → Print (`⌘P`)
3. Bottom-left dropdown → **Save as PDF**
4. Save with the same name as `.pdf`

Or, from any vector tool (Affinity Designer, Sketch, online tools),
open the SVG and export → PDF.

## Regenerate

```sh
python3 scripts/print-export.py
```

Run after editing any `design.es.svg` or `back.svg`.
