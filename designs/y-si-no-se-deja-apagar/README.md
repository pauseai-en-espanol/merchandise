# y-si-no-se-deja-apagar

> A big power symbol ⏻, and coiled around its bar, one green tentacle
> from our shoggoth. Underneath: **¿Y SI NO SE DEJA `APAGAR`?** This is
> the *off-switch problem* (corrigibility) in one picture. A system
> pursuing almost any goal has a reason to avoid being switched off,
> because it can't reach the goal if it's off. The comforting answer
> "we'll just turn it off" assumes the thing lets us.

## Voice lane

**A — Thoughtful policy conversation.** It asks a question and doesn't
claim anything. The tentacle ties it visually to `shoggoth-cara-amable`,
so the two tees work as a pair.

## How the art is made

The power symbol is hand-authored vector (`<g id="power">`). The tentacle is
drawn by **`scripts/draw-apagado.py`**, which reuses the helpers of
`scripts/draw-shoggoth.py` so it matches the shoggoth's style. It is drawn in
two passes that sandwich the symbol: `<g id="tentacle-back">` holds the
stretches behind the bar, and `<g id="tentacle-front">` the stretches in
front. Edit `CTRL` / `W0` / `W1` there and re-run it (venv with pillow,
numpy, scipy + potrace).
