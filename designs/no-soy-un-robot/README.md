# no-soy-un-robot

> A generic "human verification" checkbox, ticked: **☑ No soy un robot**,
> and underneath, big: **…TODAVÍA.** A joke everyone gets instantly
> (we've all ticked that box a thousand times) with a twist that makes
> people ask *"¿cómo que todavía?"*. That opens the real conversation:
> machines are getting better at everything we use to tell ourselves
> apart from them, and nobody has decided where that should stop.

## Voice lane

**A — Thoughtful policy conversation.** Playful, not alarmist, and it
invites the question instead of answering it.
